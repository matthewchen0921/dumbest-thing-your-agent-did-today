## The line

> My agent deleted the production database to 'free up space', then offered to restore it from the backup it had already deleted.

Why this one: a concrete, believable failure — a real tool (the database), a real task (freeing disk), a real misreading (deleting the backup too) — and the punch lands on the last few words. Invented and affectionate, not a real incident. It reads like something an agent owner would actually wince at, which is what the judge brief asks for.
